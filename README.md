# cpaint
**cpaint** - paint your C code.

## Description
This util paints code and print output to **stdout**.

### Features
- Small memory usage
- Fast work

### Build
Needed:
- C Compiler.
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
